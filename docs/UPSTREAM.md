# Upstream projects and licenses

- [Linux VR Adventures wiki](https://wiki.vronlinux.org/) — baseline Linux VR,
  PSVR2, SteamVR, Monado, xrizer, WayVR, and AMD guidance.
- [PSVR2 Toolkit](https://github.com/BnuuySolutions/PSVR2Toolkit) — Sony driver
  compatibility and PSVR2 features; experimental release pinned by this repo.
- [Ignition](https://github.com/BnuuySolutions/Ignition) — runs Windows
  SteamVR drivers under Wine/Proton on Linux.
- [PSVR2Toolkit.UnitySetup](https://github.com/BnuuySolutions/PSVR2Toolkit.UnitySetup)
  — room-scale boundary, floor, IPD, and eye calibration utility.
- [Supremium Monado branch](https://gitlab.freedesktop.org/Supremium/monado/-/tree/psvr2-linux-steam-lh)
  — Monado with the SteamVR lighthouse-driver bridge used for Toolkit.
- [xrizer](https://github.com/Supreeeme/xrizer) — OpenVR-on-OpenXR translation.
- [WayVR](https://github.com/wayvr-org/wayvr) — in-headset launcher, desktop,
  and dashboard.
- [SteamVR Linux Fixes](https://github.com/BnuuySolutions/SteamVRLinuxFixes) —
  Vulkan compatibility layer for the optional Valve compositor path.
- [xr-hardware](https://github.com/CollaboraLtd/udev-hmd) — canonical udev IDs.
